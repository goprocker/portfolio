## Overview

TaskFlow is a real-time collaborative task management application designed for small teams. Built from the ground up with modern web technologies.

## Features

- Real-time task updates across all connected clients
- Drag-and-drop kanban board
- Team workspaces with role-based permissions
- Dark mode with customizable themes

## Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express, WebSocket (ws)
- **Database**: PostgreSQL with Prisma ORM
- **Deployment**: Docker, Railway
